01五位数的四则运算 88511, 16351, ?, 10251

填 73155

把五位数写成 abcde，依次算 a+b、b−c、c×d、d÷e，再把结果挨着写。

  • 88511 → 16 | 3 | 5 | 1 → 16351
  • 16351 → 7 | 3 | 15 | 5 → 73155
  • 73155 → 10 | 2 | 5 | 1 → 10251
02倒着写，再隔项看 94, 36, 82, ?, 7, 12

填 24

把每项倒过来，得到 49, 63, 28, ?, 7, 21。奇数位是 49 → 28 → 7，偶数位是 63 → 42 → 21，两列都每次减 21。

空格在偶数位，算得 42，倒过来就是 24。

03翻倍与减三 8, ?, ?, 31, 23, 92, 46, 16

填 5、61

在倒过来的数上看，奇数位每次翻倍，得到 8、16、32、64。每个偶数位比紧挨着它前面的数小 3，于是四对是 (8, 5)、(16, 13)、(32, 29)、(64, 61)。

每个数再倒回来，得到 8, 5, 61, 31, 23, 92, 46, 16。

04每次少减三 7281981, 9141761, ?, 2160321, ?

填 4101541、3120101

前两项倒过来是 1891827、1671419，前项减后项得 220408。之后每一步减去的数少 3，依次减 220405、220402、220399。

依次得到 1891827 → 1671419 → 1451014 → 1230612 → 1010213。第三、第五项分别倒过来，就得到两个空。

05字母里的等差数列 BBCEAD, ?, BDBGBF, ?, BFAICH

填 BCCAAJ、BEBCCB

按 A=0、B=1、…、J=9 把字母逐位换成数字。BBCEAD 是 112403，每一步加 9606。

112403 → 122009 → 131615 → 141221 → 150827

把第二项 122009 和第四项 141221 逐位换回字母即可。

06围绕 P 向两边扩展 ?, NPR, ?, JLNPRTV, ?, FHJLNPRTVXZ

填 P、LNPRT、HJLNPRTVX

从 P 开始，每次在左右两头各添一个字母，沿字母表隔一位取一个。第一次添 N 和 R，第二次添 L 和 T。

P → NPR → LNPRT → JLNPRTV → HJLNPRTVX → FHJLNPRTVXZ

07两列数交错排列 0, 5, 1, ?, ?, 3, 2, ?, ?, 1, 5, 0, 8

填 4、1、2、3

  • 奇数位 0, 1, 1, 2, 3, 5, 8，从第三个数开始，每项是前两项之和。
  • 偶数位 5, 4, 3, 2, 1, 0，每次减 1。

交错放回原位，得到 0, 5, 1, 4, 1, 3, 2, 2, 3, 1, 5, 0, 8。

08字母表两端配对 AFAE, KL, ZX, BBBC, ?, R, AAAD, ?, ?

填 ED、PM、T

每三项一组。按 A=1、…、Z=26 换算。字母表两头配对，如 A ↔ Z、B ↔ Y，对应的序号加起来都是 27。

  • AFAE 变成 1、6、1、5。两两拼成 16、15，用 27 分别减去它们得 11、12，写成 KL。
  • 把四位数字相加得 13，拆成 1、3，各自配对，写成 ZX。

同理，BBBC 拼成 22、23 对应 ED，各位之和 9 对应 R。AAAD 拼成 11、14 对应 PM，各位之和 7 对应 T。

09每项拆成三块 810, 729, 539, ?, ?, 367, 379, ?, ?, 51013

填 248、256、4810、4912

取当前项的前两块 a、b，用 |a−b|、b+1、a+b 作为下一项的三块。比如 5|3|9 算出 2|4|8。

8|1|0 → 7|2|9 → 5|3|9 → 2|4|8 → 2|5|6 → 3|6|7 → 3|7|9 → 4|8|10 → 4|9|12 → 5|10|13

每块可以超过一位，所以 4810 要读成 4|8|10。

10从右向左读幂次 ?, ?, ?, 61, 2, 4, 3, 1, 3, 1, ?, 2

填 521、3、5、0

整串从右往左读，每项里的数字也倒过来。每三个数一组，依次是底数、指数、结果。

20=1，31=3，42=16，53=125。换回题目的方向，16 写成 61，125 写成 521。

521, 3, 5, 61, 2, 4, 3, 1, 3, 1, 0, 2

11序号平方，再换回字母 Z, 2, FGF, Y, 2, FBE, X, ?, ?

填 2、EGF

每三项一组。第一项取字母表序号，第二项表示平方，第三项把结果逐位换回字母。数字 1 对应 A，2 对应 B，依此类推。

从左往右两位一组，最后剩一位就单独成组。每组数字相加，按顺序拼接，再把整串倒过来。

05候选解 · 乘积拼接 18672, 31, ?, 64, 92250, ?, ?, 33

候选 18、3、750

每四项一组。末项的十位乘第二项，个位乘第三项，把两个乘积拼成第一项。比如 31×6=186，剩下的 72÷4=18。第二组可以拆成 9 | 2250，各除以 3。

20候选解 · 九格圆环 XOOOXOOOX, 45, ?, 13, OOXOXOXOO, ?, OOXXOOOXO, ?

候选 OXXXOOOOO、25、48

把 1 到 9 号位置围成一圈。两位数的个位是中心，十位是步长。中心和两侧各走这么多步的位置写 X，其余写 O。超过 9 就从 1 继续。

45 的 X 在 1、5、9，符合第一项。13 的 X 在 2、3、4。25 对应 3、5、7，48 对应 4、8、3。这套规则能对上所有已知项，仍待确认是否为原题解法。
